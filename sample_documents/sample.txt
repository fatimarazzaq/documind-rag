DocuMind RAG is a document question-answering application. It uses retrieval-augmented generation to search uploaded documents before generating an answer. The backend is built with FastAPI. The user interface is built with Streamlit. Google Gemini creates text embeddings and generates answers. FAISS stores vectors and finds similar passages. Supported upload formats in this starter are PDF, plain text, and Markdown. Text-based PDFs work best; scanned PDFs require optical character recognition (OCR).
